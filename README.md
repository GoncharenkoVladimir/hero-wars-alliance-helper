# Hero Wars Helper

Web app built with Vite, React 19, TypeScript, Tailwind CSS v4 and shadcn/ui.

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the dev server (http://localhost:3010) |
| `npm run build` | Type check, then build into `build/` |
| `npm run preview` | Serve the production build locally |
| `npm run lint` | Run ESLint |
| `npm test` | Run Vitest in watch mode |
| `npx vitest run` | Run tests once (CI) |
| `npx tsc --noEmit` | Type check only |

## Adding UI components

```
npx shadcn@latest add <component>
```

Components are copied into `src/components/ui/` and can be edited freely.
